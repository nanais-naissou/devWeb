# JavaScript Full-Stack — Practical Work

## About

This repository contains the practical work completed during the ** JavaScript Full-Stack** course.

The different exercises progressively cover backend development, databases, real-time communication, authentication, and frontend development.

## Topics Covered

* **Node.js** — HTTP servers and request handling
* **Express.js** — Routing, middleware and REST APIs
* **MongoDB / Mongoose** — Database management and CRUD operations
* **Socket.IO** — Real-time client/server communication
* **Chart.js** — Dynamic data visualization
* **Webpack** — Client-side bundling
* **JWT & Bcrypt** — User authentication and password security
* **Cookies & Middleware** — Session and access management
* **Multer** — File and image uploads
* **Fetch API** — Client/server communication
* **HTML / CSS / JavaScript** — Frontend development

## Projects

### Rock-Paper-Scissors

A multiplayer **Rock-Paper-Scissors** game developed with Node.js and Socket.IO.

It covers:

* Real-time communication
* Multiplayer game logic
* Player and score management
* Webpack-based frontend

### SellYours

A web application for **buying and selling items**.

It includes:

* User registration and login
* JWT authentication
* MongoDB database
* Item management
* Buying and selling system
* Image uploads
* Real-time updates with Socket.IO
